# NOMAD 🌿
### The AI That Turns Your Surroundings Into a Mission

**NOMAD** is an AI-powered outdoor exploration platform built for the Hacktoberfest 2026 Week 1 — **Touch Grass** challenge.

Instead of spending more time scrolling on a screen, NOMAD encourages people to step outside, explore their surroundings, and turn ordinary places into meaningful real-world adventures.

## 🌍 What It Does

NOMAD transforms a user's outdoor inspiration into an exploration mission with the help of AI.

- **AI-Powered Missions:** Generate personalized outdoor exploration missions.
- **Image-Based Exploration:** Upload an image to inspire a mission.
- **Real-World Discovery:** Encourage users to notice and explore the world around them.
- **Interactive Experience:** A simple interface designed to make getting outdoors more engaging.

## 🚀 Live Demo

**Try NOMAD:** https://nomad-1-wb4n.onrender.com

## 💻 Tech Stack

- **Frontend:** React, Vite
- **Backend:** Python, FastAPI
- **AI Integration:** Gemini API
- **Version Control:** Git and GitHub
- **Deployment:** Render

## 🛠️ How It Works

1. Open NOMAD in your browser.
2. Upload an image to inspire your exploration.
3. Let the backend process your request using the configured AI service.
4. Receive an exploration mission and take the experience beyond the screen.

## ⚙️ Run Locally

### Prerequisites
- Node.js and npm
- Python 3.10 or later
- An API key for the configured AI service

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
```

Create a `.env` file inside the `backend` directory and add the environment variable required by your backend configuration. **Never commit API keys or secrets to GitHub.**

Start the backend using the command configured in your project.
